# 📘 Smart Notes Generator Web App

A web-based intelligent application designed for engineering students to upload their study notes (TXT/PDF) and automatically generate:
- Important summaries
- Exam-oriented questions
- Downloadable PDF results
- Personal dashboard with history

This system helps students prepare effectively for Unit Tests and Semester Exams.

---

## Features

-  User Registration & Login system
-  Branch & Subject selection
-  Upload TXT or PDF notes
-  Automatic Summary Generation
-  Question Generation from notes
-  Download results as PDF
-  User Dashboard with history
-  Clean and responsive UI

## 🔄 How It Works

The Smart Notes Generator follows a simple workflow:

1. **Register / Login** – Students create an account and securely access the application.
2. **Select Subject** – Users select their engineering branch and subject.
3. **Upload Notes** – Students upload their notes in TXT or PDF format.
4. **Process Notes** – The application extracts and processes the uploaded content.
5. **Generate Results** – The system generates an important summary and exam-oriented questions.
6. **Review Results** – Students can view the generated content through the web interface.
7. **Download PDF** – Generated results can be downloaded as a PDF for offline study.
8. **View History** – Previous results can be accessed from the personal dashboard.
